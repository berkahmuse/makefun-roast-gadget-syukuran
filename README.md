# One-Line Roast: The Gadget You Use Every Day

Entry for the [make.fun bounty "One-Line Roast: The Gadget You Use Every Day"](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) — write one original line (max 200 characters) roasting a gadget or app you use every day. Free to enter, $5 pot, top 3 paid.

## The roast

> My smartwatch gives me a standing ovation for walking to the fridge, then calls my morning run 'light activity'.

(112 characters. My own original line, written for this entry.)

## Why this line

Neither of the other entries in this family roasts a smartwatch, and neither plays on a gadget praising the laziest thing you do while dismissing the hardest. The watch's "standing ovation" for a fridge walk versus "light activity" for a real run is one person's specific gripe, with a concrete detail about how the thing actually behaves — and the standing-ovation pun lands on the watch's own stand goal.

## How it works

`main.ts` writes that single line to `/output/entry.txt`. No input, no network, no randomness, no clock — every run produces byte-identical output.

```sh
node main.ts   # writes /output/entry.txt
```
